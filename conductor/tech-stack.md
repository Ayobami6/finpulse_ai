# Tech Stack

## Overview
This project is structured as a monorepo, featuring distinct frontend and backend services.

## Frontend
-   **Framework:** Next.js (16.1.6)
-   **Library:** React (19.2.3)
-   **Language:** TypeScript

## Backend
-   **Language:** Python
-   **Frameworks:** Django, Django REST Framework
-   **AI/Data Science Libraries:** pandas, scikit-learn, openai
-   **Asynchronous Processing:** Celery, Redis
-   **Real-time Communication:** Channels, Daphne
-   **Web Servers:** Gunicorn, Uvicorn
